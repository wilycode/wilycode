# Contributing

Thank you for your interest in WilyCode.

- For bugs and feature requests in a **specific PHP library**, use that library's repository and issue tracker.
- For changes to the ecosystem overview, package index or guides, open an issue or pull request in `wilycode/wilycode`.
- Keep documentation in English, use runnable examples and link to exact package repositories.
- Do not include credentials, local `.env` files, Composer `vendor/` directories or generated test artifacts in pull requests.
- Please keep descriptions grounded in released source code when documenting specific APIs.

Each library has independent versioning and maintenance. Consult the library's own CONTRIBUTING guidelines when present.
