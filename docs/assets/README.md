# WilyCode branding assets

These are the original WilyCode logo and category illustrations provided in the earlier documentation archive. They are used in the central `README.md` while keeping the current package names and catalog.

- `wilycode-symbol-light.svg` and `wilycode-symbol-dark.svg` support GitHub's light and dark appearance.
- Corresponding PNG assets are retained as alternatives.
- `icons/` contains seven category symbols in SVG and PNG. The repository README uses the PNG files for reliable display.

Preserve filenames so README image links remain stable. Do not add font files or generated build artifacts.
